# 双层路由：开放创作引擎 × 纸本档案结构母版

本技能同时保留两种能力，但它们不再争夺同一个职责。

> **开放层决定“画什么、为何这样画”；固定层决定“怎样稳定地成为同一系列”。**

## 两层职责

| 层级 | 负责的问题 | 不负责的问题 |
|---|---|---|
| **开放创作引擎** | 主题核、事实证据、张力对、核心形态、材料、色彩逻辑、自然文案、多张解释角度。 | 不强制白卡、色窗、斜轴、静物或任何版面坐标。 |
| **纸本档案结构母版** | 3:4 尺寸、纸张实体感、阅读层级、留白、卡片/窗口/文字/署名之间的系列秩序。 | 不替用户决定物候对象、色彩、文案、日期、主轴方向或叙事。 |

开放层先执行，输出一张**主题推演卡**；固定层只把这张推演卡装入可识别的纸本框架。固定层不能把“立春”改回固定嫩芽，或把“处暑”改回固定荷叶。

## 路由模式

| 用户意图 | 采用模式 | 执行顺序 |
|---|---|---|
| 只输入节气/季节主题，例如“立春”“春去秋来” | **混合模式（默认）** | 开放推演 → 纸本档案结构母版。 |
| 明确说“开放式”“别套模板”“更像概念海报/实验视觉” | **开放模式** | 只执行开放推演；不调用固定框架。 |
| 明确说“档案纸页”“保持处暑那套框架”“系列感”“固定模板” | **固定框架模式** | 使用纸本结构母版；仍以主题推演填充变量。 |
| 明确说“人物/街拍/拍立得/摄影” | **摄影模式** | 开放推演 → 镜头、人物和空间的摄影表达；不调用纸本框架。 |

## 固定框架：保留哪些，不固定哪些

### 被保留的系列秩序

1. 默认 3:4 竖版，纸面呈现可触的哑光艺术纸和低对比自然光。
2. 画面拥有外部底纸、暖白档案卡、卡片内部图像/印刷窗口、越界主形态、极简信息与可选页外署名等清晰阅读层级。
3. 档案卡只保留极浅、真实的接触式阴影；窗口和卡片边缘必须服务可信的遮挡关系，而非拼贴贴纸。
4. 一张图只有一个视觉重心与一个核心形态；它跨越窗口、卡片或底纸至少一条边界。
5. 文字密度递减：标题最清楚，副标题/注释更小，元数据最小，署名只作收束。
6. **不使用卡片内角落的装饰性红点、圆点、方块、印章或品牌式几何标记。** 任何强调色必须来自主题证据、必要文字或页外署名，不能充当无意义的版式点缀。
7. 默认署名偏好是“踏雪寻仙”；当存在自然落点时，以低饱和暖色手写放在卡片外底纸区域，居中略偏右；用户可更改或关闭。

### 必须由开放层动态决定的变量

| 变量 | 动态来源 |
|---|---|
| 主题证据与核心形态 | 用户事实、创作性解释、材料或动作。 |
| 主轴方向、跨界方式、清晰区 | 主题的视觉动词与形态逻辑。 |
| 外部底纸与窗口的色彩、明度、分区方向 | 张力对、材料和用途，而非节气默认色卡。 |
| 卡片位置、比例、窗口横竖/大小 | 画面重心、主轴所需空间、文字密度。 |
| 同源回声/投影 | 仅当能解释为同一形态的光影、反射、材质回声时使用；位置随主轴变化。 |
| 标题、注释、元数据和日期 | 用户文字或画面事实；未给地点/时间时不虚构日期。 |
| 署名位置与是否出现 | 由页面重心与用户设置决定；不合适时省略。 |

## 混合模式工作流

1. 读取 `dynamic-creative-router.md`，建立主题推演卡。
2. 判断“档案”对该主题是否有意义：是物件记录、现场笔记、材料测试、私人信件还是索引图版。
3. 读取 `art-directed-archive-master.md`，从中选择纸张和页面关系，不直接复制预设对象或色卡。
4. 应用本文件的结构母版：外部底纸 → 档案卡 → 窗口/图像区 → 越界核心形态 → 信息梯度 → 可选署名。
5. 用开放层的变量填入结构：颜色、形态、位置、光线、文案和回声都必须能解释。
6. 检查：如果删除卡片和纸张，主题仍然成立；如果换成其他主题，不会得到相同物件或相同文案。

## 多张混合系列

多张时，固定层只锁定纸张、层级、字距、阴影重量和署名策略；开放层为每张分别建立解释角度。全组允许卡片位置、窗口方向、色界、主形态、媒介痕迹与文案发生变化。

若两张除了颜色之外仍共享同一卡片位置、同一窗口、同一主形态和同一文案角度，视为失败；回到开放层重做主题推演，而不是继续换色。

## 双层验收

- [ ] 远看能读出同一系列的纸本档案秩序，但近看每张的形态、色彩与文字都来自自己的主题。
- [ ] 固定框架增强了识别度，没有夺走主题解释权。
- [ ] 节气未被固定为单一物件、单一日期、单一配色或固定短句。
- [ ] 纸张、窗口、物件和阴影均有真实的接触/材料逻辑。
- [ ] 开放模式可完全脱离纸本框架；固定模式仍可使用开放层生成真实内容。
