# 二十四节气：物候线索库（非模板）

本文件不提供固定主物、配色、日期、文案或构图。它只在用户主题是节气、而又未提供地点/材料/记忆时，给出可被创作性转译的**常见变化方向**。用户提供的地点、实际时间、材料和经验始终优先；未给出时，不将下表视为当地事实。

## 使用法

1. 从对应节气仅选择 **一项** 状态转折和 **一项** 可见证据候选。
2. 将其写成“创作性季候解释”，不用“今日”“当地”“最早”等事实承诺。
3. 主物不必是植物；可从露、光线、衣物、地表、室内外边界、容器、声音痕迹或人的动作中选择。
4. 不直接复用本表的词作为文案；文案必须根据最终画面中实际出现的材料或动作重写。

## 非节气主题的证据选择

用户输入“春去秋来”“凛冬将至”“一场雨之后”等非标准主题时，不强行匹配二十四节气。先问或推断其主要变化属于：`时间、天气、材料、人物关系、空间行为、记忆、社会事件` 中哪类，然后选择能被画面证明的一项材料或动作。

例如，“春去秋来”可围绕一张被季节改变的纸、一根半枯半新的枝、两段不同时段的光、衣物层次的交替或窗边植物的变化来创作；不要默认使用荷叶或秋叶。
