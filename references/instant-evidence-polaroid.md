# 即时成像：物证拍立得（摄影路线深化层）

本文件是 SKILL.md 摄影路线的**深化层**：当用户要求人物、街拍、拍立得、快照或摄影感时，在这里决定「即时成像如何服务于主题证据」。输入契约、推演卡、解释矩阵与验收清单以 SKILL.md 为唯一正源。

> **核心原则：** 拍立得不是滤镜，是一次「来不及布光的记录」。它的价值在于把主题证据钉进一张不可重拍的时间切片。流行的 AI 拍立得把人钉进照片；这里的拍立得把**物证**钉进照片——同一个格式，装推演出来的内容。

## 与流行拍立得的分界

| 流行玩法（合照/手办化） | 本路线（物证拍立得） |
|---|---|
| 复制同一个格式模板，换脸不换逻辑 | 推演卡决定窗口里放什么物证 |
| 主体是人，背景是装饰 | 主体是刚结束的时刻留下的可见证据 |
| 文案是梗或口号 | 文案回到「对象 + 可见状态」 |
| 无来源的事实断言 | 用户照片/记忆是事实，其余标注创作性解释 |

## 窗口里放什么

拍立得窗口只装与主题同源的物证，遵循 SKILL.md 场景筛（窗口内无可读中文）。从以下四类选一：

1. **残留物**：刚用完、刚离开的证据——湿伞、空杯、灰烬、未走完的石阶。
2. **动作截停**：一个正在消失的动作——合上的窗、翻起的纸边、递出的手。
3. **边界时刻**：明/暗、内/外、停/行的交界——路灯刚亮、卷帘落下一半。
4. **人物在场但不摆拍**：人物作为物证的尺度或动作主体出现（手、背影、侧影）；避免正面定格的「合照感」，除非用户明确要求合照。

用户提供自己的照片时，先反推其中的物证清单（材料、动作、时刻），作为事实证据优先使用；照片本身可作为窗口内的图像证据（翻拍、局部裁切），不得改写其中的人物身份与可核验事实。

## 摄影逻辑

| 参数 | 纪律 |
|---|---|
| 画幅 | 方形窗口 + 3:4 相纸白边，或整幅即窗口，二选一 |
| 镜头 | 定焦、近距、手持透视；不用广角畸变冒充纪实 |
| 光 | 现场光单一来源；闪光只在「室内夜晚、回南天」类主题成立时使用 |
| 色彩 | 由张力对推导；不用统一滤镜代替判断 |
| 质感 | 相纸显影的银盐/染料逻辑；不用「泛黄 + 颗粒」冒充时间 |

## 文字与署名

- 相纸下白边可承载一行手写短句（对象 + 可见状态）或日期位；未给日期留白，不虚构。
- 文字只出现在相纸白边；窗口内保持无可读中文。
- 署名按 SKILL.md 输入契约处理；白边存在自然落点时手写体置于下边，无落点则省略。


## 路线验收

- [ ] 删掉白边和相纸质感，画面仍是一张有主题证据的摄影，而不是空相框。
- [ ] 与流行拍立得合照并排看，本张的物证、光与文案只属于这个主题。
- [ ] 无虚构日期/地点断言；使用用户照片时已标注哪些是事实、哪些是创作性解释。
- [ ] 窗口内无可读中文；文字仅出现在相纸白边。
