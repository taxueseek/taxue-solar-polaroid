# 开放式创作路由：从主题到可执行视觉

本路由用于处理节气、季节短句、品牌主题、地点记忆、人物叙事和抽象命题。它不以“主题 → 固定静物/固定色卡/固定版式”执行，而是先建立**创作推演卡**，再选择适合该主题的媒介、形态、空间、文案与系列差异。

> **核心原则：** 视觉风格是“判断纪律”，不是一套不变构图。每次输出应由主题的具体事实、张力和用途决定；相同主题在不同用户事实、渠道和数量下可以合法地产生不同画面。

## 输入契约

| 输入 | 必要性 | 路由处理 |
|---|---:|---|
| 主题 | 必填 | 可以是节气、短句、事件、地点、物件、人物状态或品牌命题。 |
| 用途 / 媒介 | 可选 | 未给时默认“编辑视觉封面”；若给出海报、书封、社媒、展签或摄影系列，则决定密度与比例。 |
| 地点、时间、材料、记忆 | 可选 | 只要用户给出，立即成为事实优先级最高的证据；不得被默认节气词覆盖。 |
| 数量 | 可选 | 默认为 1；多张时先生成解释矩阵，而非固定版式编号。 |
| 文字 / 署名 | 可选 | 用户给精确文字时逐字保留；未给时从观察事实生成少量文案。署名只在其能服务画面重心时出现。 |
| 参考图 | 可选 | 只提取用户指定的维度，例如纸感、字形、光线或构图；不把它当作每张画的结构模板。 |

若主题过于宽泛但仍可做创作，例如“春去秋来”，直接选择一个可见证据并标注为“创作性季候解释”。只有在用户要求事实正确、具体地点、品牌事实、人物身份或精确日期时才追问或核验。

## 创作推演卡

每次先在内部完成七项推演；用户需要方案或多图时再将其显示为表格。

| 推演字段 | 目的 | 生成规则 |
|---|---|---|
| 主题核 | 一句可以用于取舍的视觉命题 | 写成“什么正在以何种方式改变”，不用空泛情绪词。 |
| 事实证据 | 防止虚假与套话 | 选用户事实、可触材料、可见动作或常见物候方向之一；标记为“用户事实”或“创作解释”。 |
| 张力对 | 决定颜色、密度和空间 | 不强制二元色场；可为“湿/干、近/远、聚/散、完整/残缺、停/行、明/暗、内/外”等任何与主题相关的对照。 |
| 核心形态 | 建立识别而非装饰 | 从主题的方向、过程、连接、动作、断裂或累积中提取；可以是物、影、线、布、人物、文字手势、空间边缘或气候痕迹。 |
| 空间规则 | 决定秩序如何服务主题 | 选择网格、折页、色块、窗口、连续摄影、空白、拼接、剪影、层叠、档案页等之一或少数几项，不默认纸卡。 |
| 媒介/材质 | 建立真实的感觉来源 | 从纸、照片、丝网印刷、铅笔、胶片、玻璃、布料、潮痕、陶、金属、自然物等中选择与主题匹配的媒介；不把颗粒/泛黄当万能质感。 |
| 文案语气 | 让文字与图像同源 | 选择观察、记录、私语、说明、索引、提问或无文字；每句必须能回到事实证据或核心形态。 |

## 形态与空间的生成式选择

不要把“一个斜轴跨纸页”作为默认答案。根据主题核决定核心形态与空间关系：

| 主题中的变化 | 更可能的形态策略 | 可选空间策略 |
|---|---|---|
| 生长、迁移、靠近、逃离 | 延伸线、轨迹、连续动作、分叉 | 出界、递进、留出去向、连续画面。 |
| 收缩、枯萎、遗忘、退去 | 断裂、回卷、稀疏、残影、遮挡 | 向内回收、压缩边缘、降低密度、缺口。 |
| 停顿、平衡、对望、纪念 | 对置、悬置、重复、间隔、留白 | 对称或近似对称、中心空场、序列。 |
| 渗透、融化、雨雾、记忆 | 扩散、叠影、半透明、浸润、模糊 | 层叠、渗边、软化分界、局部消失。 |
| 冲突、转折、惊醒、碰撞 | 折线、错位、切割、叠压、强对比 | 断面、错层、偏移网格、两个重心。 |
| 索引、档案、考据、物件记录 | 标本、编号、局部放大、裁切、图例 | 版面、边栏、密度递减、留白标注。 |

这些是**选择空间**，不是依次必须套用的模板。若用户提供了真实材料或场景，材料逻辑应优先于表格。

## 风格差异化纪律

为了与固定的“双色大场 + 纸页 + 内窗 + 斜轴”系统保持区分，本技能默认不同时锁定以下四项：水平双色色场、中央白纸、内缩窗口、斜向跨界植物。可以借用其中一至两项来服务主题，但不将它们作为母版。

每个方案先决定一个**主导视觉动词**：`生长、退去、堆积、折返、悬置、渗透、对望、切割、漂浮、索引、包裹、显影` 等。其余形式只支持这个动词，不额外装饰。

## 多张组图：解释矩阵而非模板编号

用户要求 N 张时，先生成 N 个不同的**主题解释角度**；它们必须不同于色彩换皮或同一构图左右翻转。

| 差异维度 | 要求 |
|---|---|
| 主题角度 | 每张分别看“前因、阈值、过程、残留、反转、旁观、材料、尺度、时间切片”等不同维度；根据主题任选 N 个，不能预设固定 4 个。 |
| 事实证据 | 同一主题允许从不同真实线索切入，例如处暑可以是荷叶、水痕、光线、衣料、室内空气、城市遮阴；不能全部是同一片叶。 |
| 核心形态 | 方向、尺度、连续/断裂、清晰/模糊、占比或媒介至少有一项显著变化。 |
| 空间规则 | 纸页/色块/窗口只是候选。组图至少使用两种不同空间规则，不要求每张都有卡片。 |
| 色彩 | 色彩来自张力对、材料和渠道，不能按节气固定配色；全组可共享一条明度或强调色纪律。 |
| 文案 | 每张改用不同事实句或不同叙述语气，避免同义改写。 |

多张输出前，建立“解释矩阵”。若两张在主题角度、形态、空间、材料和文案中有三项以上相同，必须合并或重做其中一张。

## 文案的真实性与自然度

文案不是节气口号。除用户要求外，使用以下任一自然句式：

- `对象 + 可见状态`：`伞沿还在滴水`、`叶面已卷起`。
- `动作 + 结果`：`风穿过窗缝，纸边轻轻翻起`。
- `时间/尺度 + 观察`：`午后的影子短了一截`。
- `索引式记录`：`湿度留下的边界`、`第一个变凉的傍晚`。
- `私语式短句`：只在用户明确需要情绪化语气时使用，且仍要能落回物件或动作。

不得默认生成诗句、格言、古典典故、宏大判断、伪引用或天气事实。未给地点、日期时，避免写“今日”“此地”“今年最早”等带核验要求的表述。

## 提示词编译顺序

先写图像的任务和媒介，再写创作推演卡的结果；不要先塞风格词。

```text
为【用途】创作【数量】张【比例】编辑视觉，主题为“【主题】”。
创作命题： 【主题核】。
事实基础： 【用户事实 / 创作性季候解释】；画面证据为【可见材料或动作】。
视觉动词与核心形态： 【动词】；【形态】以【连续/断裂/层叠/渗透等关系】组织。
空间与媒介： 【空间规则】；【纸/摄影/丝印/布料/光等材质】。
色彩与光： 由【张力对】推导【色彩与明度关系】；不使用与主题无关的默认色卡。
文字： 【少量精确文案及位置】；若无文字，说明保留的文字留白如何参与构图。
约束： 【必须保留】；避免【主题无关的漂移项】。
```

## 路由验收

- [ ] 输出能解释“为什么是这个形态、空间、材料和文案”，且理由来自主题/事实/用途。
- [ ] 不使用预设节气物件、日期、短句或四种固定构图作为默认答案。
- [ ] 没有用户事实时，已将细节表述为创作解释，未声称真实天气或本地物候。
- [ ] 多张组图存在独立主题角度，不是同卡片换色或镜像。
- [ ] 视觉语法与用户提供的参考方法在原则层面相通，但不复刻其固定空间结构、字形和物件答案。
