# 纸本档案路线：可变材料与编辑策略

当用户明确要求纸本、档案、卡片、标本、书页、印刷品或物件记录感时，调用本文件。它不是默认模板，也不规定白纸页、内窗、水平双色场、植物斜轴、标题字形或签名位置；这些都必须从主题、用途与材料事实中推导。

> **目的：** 让纸张、版面和物件关系成为主题的证据，而不是一层“高级感滤镜”。

## 先决定档案的用途

选择一种最符合主题的“文档行为”；同一张画只允许一个主导行为。

| 文档行为 | 适用主题 | 版面倾向 |
|---|---|---|
| **标本记录** | 植物、材料、季候痕迹、物件变化 | 留出观察区、局部放大、少量索引文字，物件可压页或出界。 |
| **现场笔记** | 地点、天气、行动、人物记忆 | 照片/痕迹/纸页并置，文字更像记录而不是标题。 |
| **材料测试** | 纸、布、玻璃、金属、潮痕、颜料、手工艺 | 以表面、接缝、透明度、折叠或印刷误差组织画面。 |
| **私人信件** | 情绪、关系、告别、等待、怀念 | 字迹、边距、折页和空白成为主角；物件仅作证据。 |
| **索引图版** | 系列、分类、展览、品牌视觉系统 | 使用编号、裁切、边栏、密度阶梯或图例；不要模拟真实研究结论。 |

## 材料真实性

1. 先说明纸张/媒介为何存在：它是被书写、夹带、晒过、浸湿、收纳、印刷还是测量？
2. 纸张只表现与主题有关的纤维、压纹、吸墨、折痕、潮边、透明度或边缘；不使用泛黄、脏污、撕裂和颗粒作为万能复古效果。
3. 物件与页面的接触关系要可信：压在纸上、从夹层滑出、被切口露出、被胶带固定、被湿痕覆盖或投影在其上。不要让物件无缘由悬浮。
4. 若使用摄影窗口、裁切照片或色块，让它承担证据、对照或尺度功能；不可只为复制某种版式。
5. 阴影必须来自可解释的光源和对象；不确定时减少阴影，而不要加厚黑色投影。

## 版面不是预设结构

从主题的空间需求中选择一项或两项组织原则：

| 组织原则 | 适合情形 | 可变参数 |
|---|---|---|
| 边距与空白 | 克制、等待、记录、单一物件 | 留白位置、纸页偏移、文字密度。 |
| 夹层与遮挡 | 隐藏、时间沉积、材料关系 | 纸层数量、露出比例、切口方向。 |
| 反复与编号 | 索引、收集、系列 | 单元大小、序列方向、编号功能。 |
| 裁切与局部 | 细节、证据、身体/材料观察 | 裁切尺度、清晰/模糊层级。 |
| 折叠与转向 | 转折、迁移、关系变化 | 折线角度、内外页面关系、阅读顺序。 |
| 印刷色块 | 张力对、信息分层、非摄影表达 | 色块数量、方向、明度关系、是否与物件相交。 |

不要默认使用“中央卡片 + 下方窗口”。当用户要求该结构时才使用，并为其提供主题理由。

## 文字与署名

文字选择取决于文档行为：标本记录可用编号/材料说明；现场笔记可用时间或动作；私人信件可用短句；索引图版可用图例。用最少的文字完成这项功能。

- 精确文字必须逐字写入提示词，说明位置和密度。
- 未给地点、日期或事实时，不伪造日期、坐标、档案编号或机构名。
- 署名是用户变量而非装饰：只有当页面有自然落点时加入；可在页脚、页边、折页内侧或外部留白中选择，位置由重心和文档行为决定。默认署名偏好为“踏雪寻仙”，用户可更换或关闭。

## 编译骨架

```text
为【用途】创作一张【比例】纸本档案/编辑视觉，主题为“【主题】”。
文档行为： 【标本记录/现场笔记/材料测试/私人信件/索引图版】；它服务于【主题核】。
事实与材料： 【用户事实或创作性解释】；使用【纸/布/照片/物件/潮痕等】作为可见证据。
空间组织： 使用【边距、夹层、裁切、折叠、编号、色块等】；页面/图像/物件之间的接触关系为【具体关系】。
核心形态： 【形态】以【视觉动词】组织，重点在【最清晰的证据区域】。
文字： 【必要的精确文字、语气与位置】；无文字时保留【阅读/记录留白】。
色彩与光： 由【张力对、材料和用途】推导；纸面、物件和光源保持可信。
署名： 【需要时写署名及自然落点；不需要则省略】。
避免： 【不相关的复古滤镜、假资料、无理由悬浮、过度装饰等】。
```

## 路线验收

- [ ] 若删除纸张效果，画面仍能说明主题为何需要“档案/纸本”这一媒介。
- [ ] 每一种纸面、裁切、色块、文字或物件关系均有主题/文档功能，不是固定装饰。
- [ ] 物件、页面、阴影和文字均来自同一空间与材料逻辑。
- [ ] 未伪造日期、机构、地点、研究信息或文化事实。
- [ ] 与任何固定纸卡海报的共同点仅在“材料意识与信息节制”，而非比例、物件、位置或字形复刻。
